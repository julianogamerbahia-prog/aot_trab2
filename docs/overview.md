# Visão Geral do Somador Binário

O objetivo principal deste projeto é criar um somador digital simples que opera com números de 4 bits (nibbles). Ele foi projetado para:

- RECEBER ENTRADAS

- PROCESSAR A SOMA

- EXIBIR A SAÍDA.
